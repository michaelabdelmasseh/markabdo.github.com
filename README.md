# ♟️ Chess Arena (ساحة الشطرنج)

A modern full-stack Chess application with:
1. **🤖 Play with AI Robot (5 Levels)**:
   - Level 1: Novice (600 ELO)
   - Level 2: Casual (1000 ELO)
   - Level 3: Club (1400 ELO)
   - Level 4: Expert (1800 ELO)
   - Level 5: Grandmaster (2200 ELO)
2. **👥 Pass & Play (Local Friend)**:
   - 2 players on the same device with auto-flip board option and move undo.
3. **🌐 Real-Time Online Multiplayer**:
   - Quick Match matchmaking.
   - Private room creation with 6-character code.
   - Synchronized clocks, game status, and live in-game chat.
4. **🎨 Themes & Sound**:
   - 4 Board Themes (Classic Green, Wood, Obsidian Dark, Ice Blue).
   - High-fidelity synthesized audio effects (moves, captures, checks, castling, victory fanfare).
   - Full English and Arabic (عربي) language support.

## How to Run:
The server is already running on:
**http://localhost:3000**

To restart anytime, just double-click `start.bat` or run:
```bash
node server/index.js
```
